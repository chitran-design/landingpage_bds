AGENTS.md — Vinhomes Grand Park Landing Page
Project Overview

Build a single-page real-estate landing page promoting Vinhomes Grand Park in Thu Duc City, Ho Chi Minh City, Vietnam.

The website is a static frontend-only landing page.

Primary Goal

Create a visually attractive, modern, responsive landing page that presents Vinhomes Grand Park as a premium real-estate destination.

The page should prioritize:

Strong visual hierarchy

Premium real-estate aesthetics

Clear call-to-action

Responsive design

Fast loading

Clean and maintainable HTML/CSS/JavaScript

Vietnamese language content

Technology Constraints

Use only:

HTML5

CSS3

Vanilla JavaScript

Bootstrap via CDN

Do NOT use:

React

Vue

Angular

Next.js

Nuxt

Tailwind CSS

jQuery

TypeScript

PHP

Node.js backend

Python backend

Any server-side programming language

Build tools that are unnecessary for this static page

The project must run by opening index.html directly in a browser.

Required Files

The main source file MUST be:

index.html

If additional files are necessary, use:

style.css for custom CSS

script.js for custom JavaScript

Do not create unnecessary files.

Hero Section

The hero section must contain:

A short supporting description

Create exactly 3 main feature cards.

Title:

Feature 2:

Feature 3:

Title:

The page MUST work well on:

Laptop

Mobile

img-fluid

Images

Use high-quality real-estate imagery.

If external image URLs are used:

Prefer reliable image CDNs or publicly accessible image sources.

Use meaningful alt attributes.

Ensure the page remains visually coherent if an image fails to load.

Do not create fake Vinhomes logos.

If an official logo asset is not available, use a clean text-based "VINHOMES" brand treatment instead.
