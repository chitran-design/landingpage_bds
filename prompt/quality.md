description: "Quality and completion checklist for the static Vinhomes Grand Park landing page."
Quality Rules

Before declaring the implementation complete, perform a final review.

Functional Checks

Verify:

index.html exists.

The page opens without a backend.

Bootstrap CDN is included.

Navbar works.

Navbar links point to valid sections.

CTA button works.

Mobile navigation works.

No JavaScript errors occur.

Visual Checks

Verify:

Main background uses #f2f2f2.

Main text/accent color uses #2d2d86.

Hero image appears on the right on desktop.

Hero image moves below the content on mobile.

Three feature cards are visible.

Each feature card has a different image.

Footer is visually separated from the main content.

Typography is readable.

CTA is clearly visible.

Responsive Checks

Check at least:

Desktop width

Tablet width

Mobile width

Look for:

Horizontal overflow

Broken images

Overlapping elements

Text clipping

Buttons extending outside containers

Navbar layout problems

Accessibility Checks

Verify:

Images have meaningful alt text.

Buttons have clear labels.

Links have meaningful labels.

Color contrast is reasonable.

Semantic HTML is used.

Content Checks

The content must remain in Vietnamese.

Do not make unsupported claims about:

Legal guarantees

Guaranteed investment returns

Guaranteed property appreciation

Guaranteed sales

Guaranteed ownership outcomes

The phrase "pháp lý nhanh gọn" should be presented as a marketing concept, not as an absolute legal guarantee.

Technical Checks

Do not introduce:

Backend code

Build systems

Frameworks outside Bootstrap

Unnecessary dependencies

API servers

Databases

The final implementation must remain a static HTML/CSS/JavaScript website.

Cleanup

Before finishing:

Remove unused CSS.

Remove unused JavaScript.

Remove placeholder text.

Remove broken links.

Remove unnecessary files.

Ensure filenames are simple and predictable.

The final primary entry point must remain:

index.html
